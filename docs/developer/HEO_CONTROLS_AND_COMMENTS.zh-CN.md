# Heo 评论与目录控制

Heo 使用与共享评论组件一致的启用判断。只配置 `COMMENT_ARTALK_SERVER` 或开启 `COMMENT_NOTION_ENABLE` 时，也会显示评论区域。Notion 评论开关接受布尔 `true` 或字符串 `"true"`；未启用任何服务时不渲染空评论容器。

移动端悬浮目录使用原生按钮，可通过键盘操作，提供可访问名称和展开状态。关闭时目录内容处于隐藏状态，不进入键盘焦点顺序；目录外观与显示断点保持主题原有配置。

Heo 的评论区域由 `themes/heo/index.js` 的 `LayoutSlug` 渲染，测试应覆盖此实际入口。文章设置 `comment: Hide`、处于锁定状态或全屏阅读模式时，评论区域不渲染。Heo 和 Commerce 中未被引用的 `JumpToCommentButton` 已移除。

Endspace 的评论快捷按钮同样检查服务配置、`comment: Hide` 和文章锁定状态。没有目录的文章仍可跳到已启用的评论区；首页和未启用评论的文章不显示无效入口。

Endspace 的文章工具栏由 `LayoutSlug` 接收实时解锁状态与目录数据；首页和无法解锁时由 `LayoutBase` 保留通用工具栏。密码输入期间不启动缺失正文的 404 倒计时，避免尚未解锁的正常文章被误判为不存在。

Fuwari 的文章评论区域和浮动评论入口还受 `FUWARI_ARTICLE_COMMENT` 控制。关闭此开关、设置 `comment: Hide` 或文章尚未解锁时，两者均不显示，避免按钮滚动到不存在的评论区或留下空标题和边框。

Proxio 切换到另一篇文章时会收起目录抽屉，新的文章不会继承上一篇的展开状态。

目录关闭时保留过渡动画，并设置 `aria-hidden` 和 `inert`；支持 Esc、蒙层关闭后焦点返回触发按钮，以及切换文章后复位。目前 React 18 使用 `inert=''` 表示启用；升级至 React 19 时需改为布尔属性并重新验证键盘行为。

Heo 页面顶部回弹区域使用配置的浅色或深色背景。调色板实时预览背景时，会同时更新主题容器和文档根的背景变量；关闭调色板后保持预览，离开 Heo 主题时恢复文档根原有变量，避免预览残留。
