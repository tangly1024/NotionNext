# 文章密码与服务端访问

文章密码由 Next.js 服务端验证。公开页面数据只包含 `password: "protected"` 标记、标题和摘要；正文和目录在验证成功后由 `POST /api/post/unlock` 返回，并设置 `no-store`。

- 支持 SHA-256 及历史 `md5(slug + password)` 摘要。
- 内置主题的密码框等待异步验证结果。自定义主题应使用 `await validPassword(password)`，返回值仍为布尔值。
- 验证成功会返回正文、上一篇、下一篇及推荐文章。服务暂不可用和密码错误有不同反馈。
- 旧密码 URL 和 localStorage 只尝试迁移一次，随后清除；新密码不写入 localStorage。刷新页面后需重新解锁。
- 密码文章需要服务端，纯静态导出会明确失败。UUID 入口必须属于本站目录或其子页面，并继承目录祖先的密码要求。
- 公共文章预览、搜索和 RSS 不应包含密码页面的嵌套正文。Algolia 不上传密码文章；已生成的旧索引和静态文件应在更新后重新生成。

接口按 IP 提供单实例限流。自托管反向代理应覆盖转发 IP 头，仅在代理可信时设置 `TRUST_PROXY=true`。多实例部署可在网关增加统一限流。

正文获取失败时抛出错误，使 ISR 保留上一次成功页面。此功能限制本站的正文访问；Notion 原页面自身的公开分享权限仍由 Notion 管理。
